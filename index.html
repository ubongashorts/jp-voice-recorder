Minecraft のアイテム名を日本語で読み上げる、日本語学習用の MOD を作っています。 単語だけでなくその単語を使った短い例文も聞けるようにしたいのですが、 今 287 語ぶんが足りません。その 287 文を読んでいただけると助かります。 全部で 629 個のアイテム名に使われます。

Pick a folder, allow the microphone, read each line aloud, trim if needed, save, next. Everything stays on your machine — nothing is uploaded. Reopen with the same folder to continue where you stopped.

使い方

いつでもここを見られます。急がなくて大丈夫です。

読む
大きく表示されている文を、ふつうの速さで読んでください。ゆっくり区切ったり、強調したりしなくて大丈夫です。学習者はこれを「自然な話し方の見本」として聞きます。
文を直す
文が不自然だったり、言いにくかったりしたら、その場で書き直してください。読んだとおりの文が音声といっしょに保存されるので、直しても問題ありません。むしろ助かります。単語（オレンジの文字）はそのまま残してください。
録音する
R キーで録音開始、もう一度 R で停止します。止めると自動で再生されます。スペースでもう一度聞けます。録り直すときは Backspace。
音量
録音中は下のバーが動きます。バーが右端に張りつくと音が割れるので、少しマイクから離れてください。静かな部屋で、マイクとの距離を毎回同じくらいに保つときれいに録れます。
切り取り
波形の緑の線の内側だけが保存されます。前後の無音はだいたい自動で見つけて線を置きますが、自動では切りません。線はドラッグで動かせます。言葉の頭が切れていないか、波形を見て確かめてください。
保存して次へ
Enter で保存し、次の文に進みます。ファイルは選んだフォルダに直接書き込まれます。保存ボタンを押し忘れる心配はありますが、押さずに次へ行っても、あとで戻れます。
やめるとき
そのままページを閉じて大丈夫です。次に開いて同じフォルダを選べば、録音していない最初の文から再開します。進み具合はフォルダの中のファイルそのものです。
送り方
終わったら、または途中でやめるときは、フォルダごと圧縮（zip）して、このリンクを送ってくれた人に送ってください。中の wav ファイルと manifest.json が必要です。
ブラウザ
Chrome か Edge で開いてください。ほかのブラウザではフォルダに保存できません。
Read each line at a normal pace — it is a model of natural speech, not a pronunciation drill. Rewrite any line that reads awkwardly; what you record is what gets stored. R records and stops, Space replays, Backspace redoes, Enter saves and moves on. Only the region between the green handles is kept; silence is detected and suggested but never cut for you. Stop whenever — reopen with the same folder to continue. When you are done, zip the folder and send it to whoever shared this link.
